# 项目选题说明

## 项目名称

桌游社活动管理与组队平台

## 目标用户

项目主要面向高校桌游社团成员、活动组织者和社团管理员。

普通成员希望能够方便地查看桌游和活动信息、报名参加活动；活动组织者需要发布活动并管理报名情况；管理员需要维护桌游和成员等基础信息。

## 优先实现的业务场景

本项目优先实现“桌游活动发布与报名”场景。

活动组织者可以创建一个桌游活动，填写活动名称、时间、地点和人数限制。普通成员查看活动后可以进行报名，系统记录报名信息，并根据当前报名人数判断活动是否还有剩余名额。

本周只完成 Spring Boot 工程起步，不实现具体业务逻辑。

## 核心模型

### Activity

表示一次桌游活动，主要包含：

- 活动名称
- 活动时间
- 活动地点
- 人数限制
- 活动状态

### BoardGame

表示社团中的桌游资源，主要包含：

- 桌游名称
- 桌游类型
- 适合人数
- 当前状态
